COMBOS & MACROS

, + .
— Delete. One hand, 40 ms window, BASE only, so the other hand can stay on the mouse.
D + K
— Caps Word. Both home-row Shifts, 50 ms, for SCREAMING_SNAKE names.
SYM → X
— := macro; Shift+; then = , which no single keycode gives.

HOME ROW MODS

Tap the letter, hold the mod
— on A S D F and J K L ;.
tap-preferred
— 200 ms term, 175 ms quick-tap, 150 ms prior-idle. Typing for can never emit Ctrl+O.
Cross-hand only
— hold-trigger-on-release; a mod fires only for a key on the opposite hand or a thumb.
Shift is balanced
— and drops prior-idle, so capitals survive mid-burst.

THUMB LAYER-TAPS

tap-preferred
— 200 ms term. Deleting then retyping cannot leak a SYM symbol.
220 ms quick-tap
— tap-then-hold repeats Backspace and Space; ZMK disables this by default.
No prior-idle
— SYM stays reachable mid-word, e.g. foo := bar{}.
NUM + NAV → UTIL
— conditional layer, so no thumb is spent on a rare layer.
